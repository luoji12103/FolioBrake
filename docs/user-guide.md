# User Guide

## Getting Started
1. Access the dashboard at http://localhost:1420
2. View your portfolio on the Dashboard page
3. Check signals on the Signals page
4. Monitor risk on the Risk page

## Features
- **Dashboard**: Overview of portfolio and market
- **Universe**: Manage ETF watchlist
- **Signals**: View trading signals
- **Risk**: Monitor risk state
- **Backtest**: Test strategies
- **Audit**: Validate strategies
- **Paper Trading**: Simulate trades

## Common Tasks
1. Add a new ETF: Go to Universe → Enter symbol → Add
2. Run strategy: Go to Signals → Run Strategy
3. Check backtest: Go to Backtest → Set dates → Run
4. View audit: Go to Audit → Run Audit
